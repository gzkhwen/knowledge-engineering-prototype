## 2. 页面：项目方案配置入口

### 2.1 入口位置

### 2.2 跳转参数

| 参数 | 说明 |

## 3. 页面：处理方案调整工作台

### 3.1 页面目标

在同一工作台内展示样例、Agent 对话和当前处理方案，支持知识运营人员对 Agent 生成方案进行手动调整和确认。

### 3.2 页面结构

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 左侧 | 样例文件上传、已标记问题 | 用于给 Agent 或方案调整提供样例上下文 |
| 中间 | 处理方案生成助手 | 用于展示 Agent 生成说明和发送调整意见 |
| 右侧 | 样例 / 方案 / 历史版本页签 | 当前需求重点在“方案”页签 |

### 3.3 当前原型已移除内容

- 页面顶部不展示“处理方案调整工作台”大标题栏。
- 方案页签下不展示草稿、方案校验通过、类型方案等状态标签。
- 工具卡片不展示工具状态、工具介绍、来自哪个 MCP 服务。
- 工具卡片前不展示启用复选框。

## 4. 页签：方案

### 4.1 页面目标

展示 Agent 生成的处理方案，并支持人工添加工具、删除工具、排序、编辑工具输入和参数、按顺序确认分类方案。

### 4.2 顶部上下文

| 元素 | 说明 |
| --- | --- |
| 末级类目与知识形态 | 展示当前处理方案对应的类目和知识形态 |
| 添加工具按钮 | 打开添加工具弹窗；全部分类确认后不可用 |

### 4.3 分类方案模块

| 元素 | 说明 |
| --- | --- |
| 模块标题 | `{分类名称}方案`，例如解析方案、分片方案、抽取方案 |
| 拖拽把手 | 分类方案数量大于 1 且当前分类未确认时展示 |
| 已确认标签 | 分类确认后展示在标题后方 |
| 确认方案按钮 | 当前分类可确认时展示 |
| 重新编辑按钮 | 已确认分类展示，满足顺序规则时可点击 |
| 工具列表 | 展示当前分类下已添加工具 |

### 4.4 分类方案确认规则

| 场景 | 规则 |
| --- | --- |
| 顺序确认 | 必须按页面中分类方案从上到下依次确认 |
| 越级确认 | 前一个分类未确认时，后一个分类确认按钮不可用 |
| 已确认分类 | 不可添加、删除、排序或编辑该分类下工具 |
| 重新编辑 | 只有后方相邻分类未确认时，当前已确认分类可重新编辑 |
| 保存方案 | 所有分类方案均确认后，底部“保存为处理方案”按钮可用 |

## 5. 组件：工具卡片

### 5.1 组件目标

在分类方案中展示单个工具的核心配置结果，让用户快速判断工具输入、必填参数和输出定义是否符合预期。

### 5.2 卡片标题区

| 元素 | 展示规则 |
| --- | --- |
| 拖拽把手 | 同分类内工具数大于 1 且分类未确认时展示 |
| 工具名称 | 展示工具名称 |
| 展开 / 收起图标 | 位于工具名称后方 |
| 编辑按钮 | 分类未确认时展示 |
| 删除按钮 | 分类未确认时展示 |

### 5.3 展开内容

| 区域 | 展示规则 |
| --- | --- |
| 输入 | 展示为 `参数名称：取值来源` |
| 参数配置 | 直接展示必填参数和参数值；无必填参数时展示“无必填参数” |
| 输出 | 展示输出名称，输出名称后方用标签展示格式 |

### 5.4 展示约束

- 不展示工具卡片序号。
- 不展示工具状态。
- 不展示工具介绍。
- 不展示 MCP 服务来源。
- 不展示工具启用复选框。
- 参数名称冒号后直接展示参数值，不额外拉开大间距。

### 5.5 异常提示

| 场景 | 展示方式 | 文案 |
| --- | --- | --- |
| 输入来源失效 | 工具卡片红色边框，卡片下方提示 | 输入配置异常，请检查。 |
| 必填参数缺失 | 工具卡片校验提示 | `{参数名称} 未填写` |
| 参数超出范围 | 工具卡片校验提示 | `{参数名称} 超出范围` |

## 6. 弹窗：添加工具

### 6.1 页面类型

居中弹窗。

### 6.2 打开方式

在方案页签点击添加工具按钮。

### 6.3 弹窗标题区

| 元素 | 说明 |
| --- | --- |
| 标题 | 添加工具 |
| MCP 服务 | 展示当前获取工具的 MCP 服务名称 |
| 服务版本 | 只展示版本号，例如 V1.0.0 |

### 6.4 弹窗结构

| 区域 | 内容 | 滚动规则 |
| --- | --- | --- |
| 分类区 | 全部、解析、分片、抽取 | 独立垂直滚动 |
| 工具列表区 | 当前分类下的工具 | 独立垂直滚动 |
| 参数列表区 | 当前工具入参和出参 | 独立垂直滚动 |

### 6.5 分类与工具

| 分类 | 工具 |
| --- | --- |
| 解析 | 通用解析、多模态解析、医保政策解析 |
| 分片 | 通用分片、自定义分隔符分片、分隔符递归分片、OCR解析专用分片、医保政策解析分片、视频声画同步分片 |
| 抽取 | QA提取、摘要总结、关键词提取 |

### 6.6 参数列表

| 参数类型 | 展示规则 |
| --- | --- |
| 入参 | 参数名后展示格式标签；必填参数展示“必填”标签 |
| 出参 | 参数名后展示格式标签 |

- 参数列表区不展示“入参 / 返回参数”总标题。
- 参数列表区不展示响应模板。
- “入参”和“出参”作为独立标题展示。

### 6.7 添加规则

| 场景 | 处理方式 |
| --- | --- |
| 选择未添加工具 | 确认添加按钮可用 |
| 选择已添加工具 | 确认添加按钮置灰，文案为“工具已添加” |
| 当前分类方案已确认 | 确认添加按钮置灰，文案为“方案已确认” |

## 7. 抽屉：编辑工具

### 7.1 页面类型

右侧二级抽屉，无圆角。

### 7.2 打开方式

点击工具卡片右侧编辑按钮。

### 7.3 抽屉结构

| 模块 | 说明 |
| --- | --- |
| 工具输入 | 指定哪个当前工具参数接收输入值，并配置取值方式 |
| 工具配置 | 配置除输入参数外的工具参数 |
| 工具输出 | 查看工具出参定义 |

### 7.4 模块：工具输入

| 字段 | 说明 |
| --- | --- |
| 取值方式 | 上游工具输出、待处理文件地址信息 |
| 选择上游工具 | 当取值方式为上游工具输出时展示 |
| 选择上游工具输出参数 | 当取值方式为上游工具输出时展示 |
| 取值路径 | 上游工具输出参数选择后，在选择框下方以“取值路径：{真实取值路径}”回显 |
| 选择当前工具的输入参数 | 下拉选择当前工具的一个参数作为输入参数；选择框下方展示“从当前工具的入参中选择一个参数，用于接收前面配置的输入值。” |

- 字段展示顺序为：取值方式、选择上游工具、选择上游工具输出参数、选择当前工具的输入参数。
- 当取值方式为待处理文件地址信息时，不展示选择上游工具、选择上游工具输出参数和取值路径。
- 页面不展示研发 DSL 绑定表达式，只展示用户可理解的上游工具、输出参数和取值路径。

### 7.5 输入取值规则

| 场景 | 默认值 | 是否可修改 |
| --- | --- | --- |
| 第一分类分组的第一个工具 | 待处理文件地址信息 | 否 |
| 其他工具 | 可选择上游工具输出或待处理文件地址信息 | 是 |
| 选择上游工具输出 | 默认取当前工具之前的第一个工具及其默认出参 | 是 |
| 选择待处理文件地址信息 | 不展示选择上游工具、选择上游工具输出参数和取值路径 | 是 |

### 7.6 来源工具规则

- 选择上游工具列表只展示当前工具之前的工具。
- 选择上游工具改变后，选择上游工具输出参数默认取来源工具定义中的第一个出参。
- 选择上游工具输出参数来自 Nacos 建立的出参与真实取值路径映射。
- 保存处理方案时，系统根据来源工具节点 ID 和 Nacos 出参真实取值路径生成执行侧绑定表达式。
- 绑定表达式不在编辑工具抽屉中展示，也不允许用户编辑。
- 页面不提供输出字段编辑控件。
- 如果来源工具不存在、不在当前工具之前，或所选上游工具输出参数不存在，展示输入配置异常。

### 7.7 模块：工具配置

- 展示除指定输入参数外的可配置参数。
- 参数控件根据工具定义中的类型渲染，包括单选、多选、数字输入、文本输入、多行文本、分隔符标签等。
- 不展示“展示到页面”配置。
- 修改参数后，工具卡片同步回显必填参数值。

### 7.8 模块：工具输出

- 只展示出参名称和说明。
- 不支持新增、删除或编辑输出字段。
- 输出配置由工具定义提供。

## 9. 全局交互规则

### 9.1 编辑状态

| 状态 | 页面能力 |
| --- | --- |
| 未确认分类方案 | 可添加、删除、排序、编辑工具 |
| 已确认分类方案 | 当前分类只读 |
| 全部分类已确认 | 保存处理方案按钮可用，添加工具按钮不可用 |
| 处理方案已保存 | 工作台整体只读 |

### 9.2 排序规则

- 分类方案可拖拽排序，但已确认分类不可拖拽。
- 同分类工具可拖拽排序，但工具数为 1 时不展示拖拽把手。
- 排序后需重新校验输入来源。

### 9.3 人工修改记录

- 系统可记录方案是否发生过人工添加、删除、排序、输入来源或参数修改。
- 工作台页面不展示“智能方案 / 智能+人工”标签。

## 10. 校验规则汇总

| 校验位置 | 校验项 | 触发时机 | 处理方式 |
| --- | --- | --- | --- |
| 添加工具弹窗 | 工具是否已添加 | 选择工具 | 按钮置灰并显示“工具已添加” |
| 添加工具弹窗 | 分类方案是否已确认 | 确认添加 | 按钮置灰并显示“方案已确认” |
| 分类方案 | 是否按顺序确认 | 点击确认方案 | 非当前可确认分类不可确认 |
| 分类方案 | 是否存在输入配置异常 | 点击确认方案 | 阻止确认 |
| 工具卡片 | 来源工具是否仍在当前工具之前 | 删除或排序后 | 标红并提示 |
| 工具卡片 | 所选上游工具输出参数是否仍存在 | 来源工具或工具定义变化后 | 标红并提示 |
| 工具卡片 | 必填参数是否完整 | 点击确认方案 | 阻止确认并提示 |
| 保存按钮 | 是否所有分类已确认 | 点击保存 | 未全部确认时按钮不可用 |

## 11. 状态定义 / 标签规范

| 标签 / 状态 | 展示位置 | 说明 |
| --- | --- | --- |
| 已确认 | 分类方案标题后方 | 该分类方案已锁定 |
| 工具已添加 | 添加工具弹窗确认按钮 | 当前选择工具已在方案中 |
| 方案已确认 | 添加工具弹窗确认按钮 | 当前工具所属分类已确认 |
| 输入配置异常，请检查。 | 工具卡片 / 编辑抽屉 | 上游来源失效 |
