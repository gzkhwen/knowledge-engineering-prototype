# PowerAgent 知识工程原型

这是知识工程产品嵌入 PowerAgent 后的新交互原型，当前原型已替换原 `05-产品原型/prototype` 目录下的旧原型。

## 原型工作约定

- 后续所有原型设计、调整、迁移和视觉优化，都统一使用 Product Design 插件作为原型工作方式。
- 旧原型只作为业务逻辑、交互细节、示例数据和演示流程的参考来源，不再作为新原型的技术方案或 UI 规范基线。
- 新原型的 UI 规范以 PowerAgent 实际上线界面为准，保持同一套按钮、表格、筛选、弹窗、抽屉、分页和提示样式。
- 如果需要补充或重构模块，优先保持当前 React/Vite 原型结构，不引入新的原型技术栈。

## 本地运行

```bash
npm run dev
```

## 构建验证

```bash
npm run build
```

## 当前范围

当前原型重点覆盖以下模块：

- 管理端：接入 MCP 服务
- 管理端：工具管理
- 运营端：知识空间管理
- 运营端：查看知识空间类目
- 运营端：方案工作台

其他模块只保留菜单入口，不做完整迁移。
