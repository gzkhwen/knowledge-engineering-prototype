## 1. 模块定位

### 1.1 一句话定位

在项目知识空间内，按照"先确认知识形态为非结构化切片，再选知识类目"的顺序，从标准化文档候选集中选择目标内容，配置常规切片参数，执行切片构建任务，生成并管理状态独立的知识切片。

### 1.2 模块价值

非结构化切片是 RAG（检索增强生成）系统的核心数据基础。本模块通过将长篇的标准化文档按策略切分为语义完整、长度适中的知识切片，解决大模型上下文窗口限制与精准检索需求之间的矛盾。通过支持知识运营人员配置常规切片参数（如切片长度、重叠比例等），赋予其根据不同文档特征优化切片质量的能力，从而提升最终的检索精度与生成质量。

### 1.3 本模块负责

- 读取项目方案，识别知识形态为"非结构化切片"的
- 支持在选定该知识形态下，联动选择对应的**知识类目**。
- 提供从标准化文档候选集中选择目标文档的交互入口
- 支持知识运营人员配置常规切片参数（切片长度、重叠比例、最小块长度等）
- 触发并执行切片构建任务，记录任务执行状态与历史
- 生成知识切片，建立切片与来源标准化文档的追溯关系
- 管理知识切片的启用/停用状态，支持单条或批量操作
- 提供知识切片结果的列表查看与详情查阅

### 1.4 本需求不做

- 结构化知识（如问答对、SOP、图谱）的构建（由 M-PRD-7 负责）
- 原始材料的接入与解析治理（由 M-PRD-5、M-PRD-6 负责）
- 将切片打包为最终可分发的知识包（由 M-PRD-10 负责）
- 切片结果的冲突检测与深度质检（由 M-PRD-9 负责，属二期能力）
- 切片工具配置参数的持久化回写到项目方案与模板沉淀（二期能力）
- 高级切片策略（如基于 LLM 的语义切片、文档树结构切片）的实现（一期仅支持固定长度与滑动窗口等基础策略）

### 1.5 上下游边界

- **上游输入**：
  - **项目方案**（来自 M-PRD-4）：提供知识类目与知识形态的定义，作为切片构建的分类依据。
  - **标准化文档候选集**（来自 M-PRD-6）：提供已完成解析与清洗的文档，作为切片构建的内容输入。
- **下游输出**：
  - **知识切片**：输出状态为"启用"的知识切片，供 M-PRD-10 知识包管理模块消费并打包，最终供 M-PRD-11 构建结果验证模块进行搜索测试。
- **与其他模块的关系**：
  - **M-PRD-7 结构化知识构建**：与本模块同属知识构建环节，两者相互独立。同一份标准化文档可同时进入这两个通道，互不影响。
 - **M-PRD-10 知识包管理**：本模块产出的启用的知识切片，将作为知识包的组成部分。

## 3. 使用场景

### 3.1 场景一：基于默认参数发起切片构建

- **场景描述**：知识运营人员针对某个"非结构化切片"知识形态及其中的某个或某些知识类目，选择了若干标准化文档，直接使用系统默认的切片参数发起构建任务。
- **触发角色**：知识运营人员
- **前置条件**：项目知识空间与项目方案均处于启用状；已选择至少一份处于启用状态的标准化文档。
- **预期结果**：系统创建切片构建任务，按默认参数执行切片；任务完成后，生成新的知识切片，切片状态默认为"停用"，并正确记录来源追溯信息。

### 3.2 场景二：自定义参数优化切片质量

- **场景描述**：知识运营人员发现某类文档（如操作手册）段落较短，默认切片长度导致语义被割裂。因此在发起切片构建时，手动调整了切片长度和重叠比例参数。
- **触发角色**：知识运营人员
- **前置条件**：同场景一。
- **预期结果**：系统使用用户自定义的参数配置执行切片任务；生成的切片长度和重叠部分符合预期；自定义参数作为本次任务的元数据被记录，但不回写修改项目方案的默认配置。

### 3.3 场景三：查阅与管理切片状态

- **场景描述**：切片构建任务完成后，知识运营人员进入结果列表，抽查切片质量，并将符合要求的切片批量变更为"启用"状态，以便后续纳入知识包。
- **触发角色**：知识运营人员
- **前置条件**：切片构建任务已完成，存在知识切片记录。
- **预期结果**：切片状态成功更新为"启用"；若对已被知识包引用的切片执行"停用"操作，系统会给出明确的风险提示。

### 3.4 异常/边界场景：项目方案调整后的切片处理

- **场景描述**：知识运营人员在 M-PRD-4 中将某个知识类目的知识形态从"非结构化切片"修改为了"问答库"，随后回到本模块查看。
- **触发角色**：知识运营人员
- **前置条件**：该知识类目下已有构建完成的知识切片。
- **预期结果**：该类目下已有的知识切片变为孤立状态，不自动删除或停用，需知识运营人员手动处理；该类目不再提供新的切片构建入口。

## 4. 核心对象

> 仅写业务对象，不写数据库表、英文字段名、SQL、接口路径。

| 对象 | 是否新对象 | 对象说明 | 关键属性（中文） | 关联状态/关系 |
|------|------------|----------|-----------------|---------------|
知识切片 | 否 | 经非结构化切片通道形成的知识结果 | 切片ID、切片内容、所属类目、知识形态 | 状态：启用/停用；关系：N:1 知识类目，N:1 知识形态 |
| 知识形态 | 否 | 目标知识的组织形式，切片通道的形态固定为"非结构化切片" | 形态名称 | 关系：N:N 知识类目（在同一项目方案内） |
| 知识类目 | 否 | 用于承载某一类目标知识内容的配置项 | 类目名称 | 关系：N:N 知识形态（在同一项目方案内） |
| 标准化文档 | 否 | 原始材料经过标准化处理后的统一处理对象 | 文档ID、内容 | 关系：1:N 知识切片 |


### 4.1 对象约束补充

- **知识切片的归属关系**：每条知识切片归属于且仅归属于一个知识类目，不可跨类目复用。
- **知识切片的追溯关系**：每条知识切片必须明确记录其来源的标准化文档。
- **切片参数配置的生效范围**：一期阶段，参数配置仅对当前触发的单次切片构建任务生效，不具有全局继承性，也不回写至项目方案。
- **切片构建任务的独立性**：同一知识类目可发起多次切片构建任务，各次任务及其产出的知识切片相互独立，互不覆盖。

## 5. 业务事实归属与状态一致性

### 5.1 业务事实归属

- **能否进行切片构建**的唯一事实来源是：M-PRD-4 项目方案中该知识类目的知识形态是否包含"非结构化切片"。
- **切片输入源的可用性**的唯一事实来源是：M-PRD-6 中标准化文档对象的启用状态。
- **知识切片的启用状态**的唯一事实来源是：本模块中知识切片对象的启用状态属性。M-PRD-10 知识包管理在打包时必须读取此状态。

### 5.2 状态一致性要求

- 本文档涉及的对象状态必须与《概念模型 V4.2》一致。
- 知识切片仅有"启用"和"停用"两种状态。新生成的知识切片初始状态必须为"停用"。
- 切片构建任务状态包括"进行中"、"已完成"、"已失败"，状态流转必须单向且终态不可逆。

## 7. 详细功能需求


### 7.1 功能点一：构建目标选择（先形态，后类目）

#### 功能描述
知识运营人员进入切片通道，系统默认锁定知识形态为"非结构化切片"，用户需在此形态下选择具体的知识类目。

#### 触发角色
- 知识运营人员

#### 前置条件
- 项目知识空间已创建，且当前项目方案已生效。

#### 输入
- 用户的类目选择操作。

#### 正常流程
1. 用户进入"非结构化切片构建"模块。
2. 系统界面明确标识当前知识形态为"非结构化切片"（作为不可更改的前置条件）。
3. 系统读取当前项目方案，筛选出配置为"非结构化切片"形态的所有知识类目。
4. 系统以下拉列表形式展示这些匹配的知识类目。
5. 用户选择具体的目标知识类目。

#### 异常/拦截
- 当 [项目方案中未配置任何形态为"非结构化切片"的类目] 时，系统应：类目列表置空，并给出醒目提示"当前项目方案未包含非结构化切片构建目标，请前往项目方案配置"。

#### 输出结果
- 确定的构建目标组合：[知识形态（固定为非结构化切片） + 知识类目]。

#### 状态变化
- 无。

#### 业务规则
- **形态优先与过滤规则**：本模块的类目选择器必须严格受限于"非结构化切片"形态，绝不展示被定义为 FAQ、术语等结构化形态的类目。

### 7.2 功能点一：发起切片构建与参数配置

#### 功能描述
允许知识运营人员针对特定知识类目，选择标准化文档，配置切片参数，并触发切片构建任务。

#### 触发角色
- 知识运营人员

#### 前置条件
- 项目知识空间状态为"启用"。
- 项目方案状态为"启用"。
- 目标知识类目的知识形态包含"非结构化切片"。
- 至少选择了一份状态为"启用"的标准化文档。

#### 输入
- 目标知识类目 ID
- 选中的标准化文档 ID 列表
- 切片参数配置项：
  - **切片策略**：固定值"改进的固定长度切片"（一期暂不开放策略选择）
  - **切片长度（Chunk Size）**：数值，范围 100-2000，默认值 512
  - **重叠比例（Overlap Ratio）**：百分比，范围 0%-50%，默认值 20%
  - **最小块长度（Min Chunk Size）**：数值，范围 10-200，默认值 50

#### 正常流程
1. 知识运营人员进入切片构建配置页，系统展示当前项目方案中支持"非结构化切片"的知识类目树。
2. 知识运营人员选中某个末级知识类目。
3. 系统展示当前项目内状态为"启用"的标准化文档候选集。
4. 知识运营人员勾选一份或多份目标标准化文档。
5. 知识运营人员展开"高级参数配置"面板，查看默认参数。
6. 知识运营人员修改切片长度和重叠比例，点击"确认发起"。
7. 系统校验参数合法性与前置条件。
8. 系统生成一条切片构建任务记录，状态置为"进行中"。
9. 系统异步执行切片处理逻辑。

#### 异常/拦截
- 当项目方案中无"非结构化切片"知识类目时，系统应展示空态提示"当前项目方案中无需构建非结构化切片的知识类目"。
- 当未选择任何标准化文档时，系统应拦截提交并提示"请至少选择一份标准化文档"。
- 当切片长度小于最小块长度时，系统应拦截提交并提示"切片长度不能小于最小块长度"。
- 当重叠比例设置过大（导致重叠字符数超过切片长度的 50%）时，系统应提示"重叠比例不建议超过 50%"。

#### 输出结果
- 新增一条切片构建任务记录。

#### 状态变化
- 切片构建任务：初始状态为"进行中"。

#### 业务规则
- **参数独立性**：本次配置的参数仅对当前任务生效，不影响历史任务，也不修改系统默认值。
- **任务并发**：同一知识类目允许同时存在多个进行中的切片构建任务，但系统应在发起时给予提示以防误操作。
- **文档复用**：同一份标准化文档可以在不同的切片构建任务中被重复选择。

#### 与其他模块的边界/影响
- 本功能依赖 M-PRD-4 提供知识类目判断依据。
- 本功能依赖 M-PRD-6 提供标准化文档候选集。

### 7.3 功能点二：切片构建任务执行与结果生成

#### 功能描述
系统后台异步执行切片构建任务，根据设定的参数将标准化文档切割为知识切片，并记录追溯关系。

#### 触发角色
- 系统自动执行（承接功能点一的触发）

#### 前置条件
- 存在状态为"进行中"的切片构建任务。

#### 输入
- 切片构建任务中的输入文档列表与参数配置。

#### 正常流程
1. 系统读取任务指定的标准化文档内容。
2. 系统应用设定的切片参数（切片长度、重叠比例、最小块长度）。
3. 系统在自然语言边界（如句号、换行符）处寻找最接近目标长度的切割点，执行文本分割。
4. 对相邻切片应用重叠比例计算，保留上下文连贯性。
5. 过滤掉长度小于"最小块长度"的碎片文本。
6. 为生成的每个切片对象写入来源追溯信息（所属类目、来源文档 ID、任务 ID）。
7. 任务执行完毕，更新任务状态，记录产出切片数量。

#### 异常/拦截
- 当读取标准化文档内容失败时，系统应将任务状态更新为"已失败"，并记录失败原因。
- 当文档内容过短，无法满足最小块长度要求时，系统应完成任务但产出切片数为 0。

#### 输出结果
- 若干条新增的知识切片记录。
- 更新后的切片构建任务记录。

#### 状态变化
- 知识切片：新增记录，初始状态统一为"停用"。
- 切片构建任务：由"进行中"变为"已完成"或"已失败"。

#### 业务规则
- **默认停用规则**：新产出的知识切片默认为"停用"状态，需知识运营人员手动确认启用后，方可被下游使用。
- **失败无残留规则**：失败的构建任务不产出任何知识切片，也不影响已有知识切片的状态。

#### 与其他模块的边界/影响
- 本功能不对外直接暴露接口，其产出的"停用"状态切片暂不会被 M-PRD-10 知识包管理读取。

### 7.4 功能点三：知识切片状态管理（启用/停用）

#### 功能描述
知识运营人员对已生成的知识切片进行查阅，并将其状态在"启用"和"停用"之间切换。

#### 触发角色
- 知识运营人员

#### 前置条件
- 存在已生成的知识切片。

#### 输入
- 目标知识切片 ID 列表。
- 目标状态（启用/停用）。

#### 正常流程
1. 知识运营人员在切片结果列表页勾选一条或多条知识切片。
2. 点击"批量启用"或"批量停用"按钮。
3. 系统校验当前切片状态与目标状态。
4. 若操作为"停用"，系统额外校验该切片是否已被 M-PRD-10 中状态为"启用"的知识包引用。
5. 若存在引用关系，系统弹窗提示风险并要求二次确认。
6. 知识运营人员确认后，系统更新选中切片的状态。
7. 系统返回操作结果提示（成功数量/失败数量）。

#### 异常/拦截
- 当对已处于目标状态的切片执行切换时，系统忽略该操作或提示"切片已处于该状态"。

#### 输出结果
- 更新后的知识切片状态。

#### 状态变化
- 知识切片：由"停用"变为"启用"，或由"启用"变为"停用"。

#### 业务规则
- **引用解耦规则**：停用已被知识包引用的知识切片时，系统仅改变切片自身状态，不自动从知识包中移除引用关系（解绑动作需由运营人员在 M-PRD-10 中处理）。
- **类目失效处理**：若项目方案中某知识类目被删除或形态改变，该类目下已有切片变为孤立数据，其启用/停用状态保持不变，由运营人员决定是否手动停用。

#### 与其他模块的边界/影响
- 本功能的输出直接影响 M-PRD-10 知识包管理。M-PRD-10 在打包时仅能包含状态为"启用"的知识切片。

## 8. 自然语言伪代码

### 8.1 主流程：发起切片构建任务

```text
当 知识运营人员 执行 发起切片构建 动作时，系统执行：
1. 校验 项目知识空间状态是否为"启用"；
2. 若 否，则返回 拦截提示"当前项目知识空间已停用，无法进行切片构建"；
3. 校验 项目方案状态是否为"启用"；
4. 若 否，则返回 拦截提示"当前项目方案已停用，无法进行切片构建"；
5. 读取项目方案，过滤出形态为 [非结构化切片] 的 [知识类目列表]；
6. 若 [列表为空]，则返回 [拦截提示：该形态下无可用知识类目，请调整项目方案]；
7. 接收用户选择的 [知识类目]；
8. 接收用户从候选集中勾选的 [标准化文档列表]；
9. 若 [文档列表为空]，则返回 [拦截提示：请选择要处理的文档]；
10. 校验 切片参数配置（切片长度 >= 最小块长度，重叠比例在合法范围内）；
11. 若 参数不合法，则返回 拦截提示"切片参数配置无效，请检查"；
12. 创建 切片构建任务对象，记录选中的文档、配置的参数，状态置为"进行中"；
13. 触发 异步切片执行流程；
14. 返回 成功提示"切片构建任务已发起，请在任务列表查看进度"。
```

### 8.2 异常流程：切片构建任务失败处理

```text
当 切片构建任务 执行过程中发生 内部异常或文档读取失败 时，系统执行：
1. 判断 异常是否可恢复；
2. 若 不可恢复，则阻止 继续切片生成；
3. 将 切片构建任务状态 更新为"已失败"；
4. 记录 具体的失败原因至任务日志；
5. 保持 该任务已生成的临时切片数据回滚（不落库）；
6. 保持 历史已存在的知识切片状态不变。
```

### 8.3 状态切换流程：批量停用知识切片

```text
当 知识运营人员 执行 批量停用知识切片 动作时，系统执行：
1. 校验 传入的切片列表是否为空；
2. 校验 这些切片当前状态是否为"启用"；
3. 检查 列表中是否有切片已被 M-PRD-10 中处于"启用"状态的知识包引用；
4. 若 存在引用关系，则返回 交互提示"以下切片已被知识包引用，停用后将影响知识包内容，是否继续？"；
5. 若 知识运营人员选择取消，则终止操作；
6. 若 知识运营人员确认继续，或不存在引用关系，则将选中的切片状态更新为"停用"；
7. 返回 成功提示"已成功停用 X 条知识切片"。
```

## 9. 关键业务规则

| 规则编号 | 规则内容 | 优先级 |
|----------|----------|--------|
| R-M-PRD-8-01 | **形态限定**：非结构化切片是一种明确的知识形态，仅当项目方案中某知识类目的知识形态包含"非结构化切片"时才可为其构建切片。 | 高 |
| R-M-PRD-8-02 | **统一输入**：切片构建的直接输入必须是标准化文档，严禁直接处理原始材料。 | 高 |
| R-M-PRD-8-03 | **状态默认**：新产出的知识切片默认为"停用"状态，需人工确认启用后方可进入知识包。 | 高 |
| R-M-PRD-8-04 | **追溯强制**：每条知识切片必须且只能归属于一个知识类目，且必须记录来源标准化文档的 ID。 | 高 |
| R-M-PRD-8-05 | **通道独立**：同一份标准化文档可同时进入非结构化切片通道与结构化通道，两者独立运行，互不干扰。 | 高 |
| R-M-PRD-8-06 | **参数隔离**：一期阶段，切片参数配置仅作用于当前任务，不修改系统默认值，也不回写到项目方案。 | 中 |
| R-M-PRD-8-07 | **结果保留**：项目方案中的知识类目或知识形态调整后，已生成的知识切片不自动删除或改写，是否废弃由人工决定。 | 高 |
| R-M-PRD-8-08 | **解绑解耦**：停用已被知识包引用的知识切片时，不自动从知识包中移除引用关系。 | 中 |

## 13. 依赖与约束

### 13.1 业务依赖

- 本模块依赖 M-PRD-4 项目方案配置提供的已启用项目方案，获取哪些知识类目的知识形态为"非结构化切片"。
- 本模块依赖 M-PRD-6 标准化处理提供的已启用标准化文档，作为切片构建的候选输入范围。
- 本模块的输出（启用的知识切片）是 M-PRD-10 知识包管理的前置依赖。

### 13.2 业务约束

- 切片构建的输入必须是标准化文档，不可直接处理原始材料。
- 非结构化切片仅在项目方案中该知识类目的知识形态包含"非结构化切片"时才可构建。
- 新产出切片默认为"停用"状态，不自动进入知识包。
- **一期基础版切片参数配置范围**：仅支持常规参数（切片长度、重叠比例、最小块长度），不支持切片策略选择或高级参数（如相似度阈值）。
- **一期不支持**：工具配置的深度定义与回写至项目方案（属二期能力）；切片结果整形与去重（属二期切片增强范围）；权威源层级应用（属二期质检范围）；基于 LLM 或语义的高级切片策略（属二期或后续阶段）。

### 13.3 外部影响说明

- 本模块的输出会直接影响：**M-PRD-10 知识包管理**（知识切片是知识包的核心组成部分之一）；**M-PRD-11 构建结果验证**（知识切片是搜索测试的主要对象之一）。
- 本模块依赖的共享规则包括：《概念模型 V4.2》中的知识切片、标准化文档、知识类目对象定义；《角色矩阵与权限边界 V3.2》中的知识运营人员权限定义；《知识工程引擎与工具体系设计 V1.0》中的切片工具体系定义。
