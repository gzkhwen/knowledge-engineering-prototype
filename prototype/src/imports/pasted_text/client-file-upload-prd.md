## 1. 模块定位

### 1.1 一句话定位

为企业客户提供原始材料上传能力，将文件接入项目知识空间，形成可供标准化处理的原始材料。

### 1.2 模块价值

- **对企业客户**：提供简单、明确的材料提交入口，无需理解复杂知识治理流程
- **对知识运营**：获取项目所需的原始输入材料，启动知识工程流程
- **对平台**：建立标准化的材料接入通道，支持来源追溯与安全管理

### 1.3 本模块负责

- 企业客户在客户端上传文件
- 查看本人上传结果
- 文件安全检查与基础元数据提取

### 1.4 本需求不做

- 项目方案配置
- 工具选择与参数配置
- 标准化处理编辑
- 知识构建执行
- 质检规则配置
- 模板管理
- 结果验收（由 C-PRD-2 负责）

### 1.5 上下游边界

- **上游输入**：企业客户本地文件
- **下游输出**：原始材料对象（进入 M-PRD-5 原始材料接入与管理）
- **与其他模块的关系**：
  - M-PRD-5 原始材料接入与管理：承接上传后的原始材料管理
  - M-PRD-6 标准化处理：对原始材料执行标准化处理
  - C-PRD-2 结果验收：企业客户后续查看知识包结果

## 3. 使用场景

### 3.1 场景一：企业客户上传项目材料

- **场景描述**：企业客户需要将产品说明、售后政策等原始材料提交到项目知识空间
- **触发角色**：企业客户
- **前置条件**：
  - 项目知识空间已创建并启用
  - 企业客户已获得项目访问权限
- **预期结果**：文件成功上传，形成原始材料记录，可查看上传状态

### 3.2 场景二：企业客户查看上传历史

- **场景描述**：企业客户查看本人在该项目中已上传的文件列表及状态
- **触发角色**：企业客户
- **前置条件**：已有上传记录
- **预期结果**：展示本人上传的文件列表、上传时间、处理状态

### 3.3 异常/边界场景：文件格式不支持

- **场景描述**：企业客户尝试上传系统不支持的文件格式
- **触发角色**：企业客户
- **前置条件**：选择非支持格式文件
- **预期结果**：系统拦截上传，提示支持的文件格式范围

## 4. 核心对象

| 对象         | 是否新对象 | 对象说明                       | 关键属性（中文）                                           | 关联状态/关系                                        |
| ------------ | ---------- | ------------------------------ | ---------------------------------------------------------- | ---------------------------------------------------- |
| 原始材料     | 否         | 实际进入系统的原始输入内容     | 来源类型、文件名、文件大小、上传时间、上传人、项目知识空间 | 归属项目知识空间，一份原始材料默认对应一份标准化文档 |
| 项目知识空间 | 否         | 某个客户项目的知识工程运行容器 | 项目名称、行业、领域、场景、启用状态                       | 企业客户上传的材料归属该项目空间                     |

### 4.1 对象约束补充

- **原始材料的唯一性规则**：同一项目中，同一用户上传的同一文件（按文件名 + 大小 + 上传时间综合判断）可存在多条记录，不强制去重
- **原始材料的归属关系**：原始材料归属项目知识空间，同时记录上传人信息
- **原始材料的可用条件**：项目知识空间处于启用状态时，企业客户可上传材料

## 5. 业务事实归属与状态一致性

### 5.1 业务事实归属

- **原始材料来源的唯一事实来源**：原始材料对象中的"来源类型"和"上传人"字段
- **上传状态的唯一事实来源**：原始材料对象中的处理状态字段

### 5.2 状态一致性要求

- 原始材料不单独定义复杂生命周期状态
- 上传状态包括：上传中、上传成功、上传失败
- 状态命名与《概念模型》保持一致

## 7. 详细功能需求

### 7.1 功能点一：文件上传

**功能描述**
企业客户选择本地文件并上传至项目知识空间，形成原始材料记录。

**触发角色**
企业客户

**前置条件**

- 项目知识空间已创建并启用
- 企业客户已登录并具有该项目访问权限

**输入**

- 文件（支持格式：PDF、Word、Excel、PPT、TXT、图片等）
- 项目知识空间 ID

**正常流程**

1. 企业客户进入文件上传页面
2. 选择本地文件
3. 系统校验文件格式与大小
4. 执行文件安全检查（病毒扫描、格式检查）
5. 上传文件至服务器
6. 创建原始材料记录
7. 返回上传成功结果

**异常/拦截**

- 当文件格式不支持时，系统应：拦截上传，提示支持的文件格式列表
- 当文件大小超过限制时，系统应：拦截上传，提示最大文件大小限制
- 当文件安全检查未通过时，系统应：拦截上传，提示安全检查失败原因
- 当项目知识空间已停用时，系统应：拦截上传，提示项目不可用

**输出结果**

- 上传成功/失败提示
- 原始材料记录 ID

**状态变化**

- 原始材料：由"不存在"变为"上传成功"或"上传失败"

**业务规则**

- 支持单文件上传和批量上传
- 大文件支持分片上传、断点续传
- 上传后自动执行文件安全检查

**与其他模块的边界/影响**

- 本功能不负责：标准化处理、知识构建
- 本功能对下游的输出是：原始材料对象
- 下游如需继续处理，由 M-PRD-5 原始材料接入与管理承接

------

### 7.2 功能点二：上传记录查看

**功能描述**
企业客户查看本人在该项目中已上传的文件列表及状态。

**触发角色**
企业客户

**前置条件**

- 企业客户已登录
- 企业客户具有该项目访问权限

**输入**

- 项目知识空间 ID

**正常流程**

1. 企业客户进入上传记录页面
2. 系统查询该企业客户在本项目的上传记录
3. 展示文件列表（文件名、大小、上传时间、状态）

**异常/拦截**

- 当无上传记录时，系统应：展示空状态提示
- 当企业客户无项目访问权限时，系统应：拦截访问，提示权限不足

**输出结果**

- 上传记录列表

**状态变化**

- 无状态变化

**业务规则**

- 仅展示本人上传的记录
- 按上传时间倒序排列

**与其他模块的边界/影响**

- 本功能不负责：查看他人上传记录、管理原始材料
- 本功能对下游无直接影响

## 8. 自然语言伪代码

### 8.1 主流程：文件上传流程

当企业客户执行文件上传时，系统执行：

1. 校验企业客户是否已登录；
2. 若未登录，则返回"请先登录"提示；
3. 校验企业客户是否具有该项目知识空间访问权限；
4. 若权限不足，则返回"无项目访问权限"提示；
5. 校验项目知识空间是否处于启用状态；
6. 若项目已停用，则返回"项目不可用"提示；
7. 校验文件格式是否在支持范围内；
8. 若格式不支持，则返回"不支持的文件格式"提示；
9. 校验文件大小是否超过限制；
10. 若文件过大，则返回"文件大小超过限制"提示；
11. 执行文件安全检查；
12. 若安全检查未通过，则返回"安全检查失败"提示；
13. 创建原始材料对象，记录上传人、项目知识空间、文件信息；
14. 更新原始材料状态为"上传成功"；
15. 返回上传成功结果及原始材料 ID。

### 8.2 异常流程：上传失败处理

当发生上传异常时，系统执行：

1. 判断异常类型（网络中断、服务器错误、安全检查失败等）；
2. 若成立，则阻止上传完成；
3. 返回明确的失败原因提示；
4. 保持原始材料状态为"上传失败"或不清除临时记录。

### 8.3 状态切换流程：上传状态更新

当系统执行上传状态更新时，系统执行：

1. 校验原始材料对象是否存在；
2. 校验当前状态是否允许更新；
3. 若不满足，则返回"状态更新失败"提示；
4. 若满足，则将原始材料从"上传中"更新为"上传成功"或"上传失败"；
5. 返回状态更新成功结果。

## 9. 关键业务规则

| 规则编号     | 规则内容                                         | 优先级 |
| ------------ | ------------------------------------------------ | ------ |
| R-C-PRD-1-01 | 企业客户仅可上传文件至其有访问权限的项目知识空间 | 高     |
| R-C-PRD-1-02 | 上传文件必须通过安全检查方可入库                 | 高     |
| R-C-PRD-1-03 | 原始材料归属关系以项目知识空间 + 上传人共同确定  | 高     |
| R-C-PRD-1-04 | 企业客户仅可查看本人上传记录，不可查看他人记录   | 高     |
| R-C-PRD-1-05 | 项目知识空间停用后，禁止新文件上传               | 中     |

## 10. 异常与边界情况

| 场景         | 触发条件               | 处理方式           | 用户提示                                                  |
| ------------ | ---------------------- | ------------------ | --------------------------------------------------------- |
| 输入为空     | 未选择文件             | 拦截上传           | "请选择要上传的文件"                                      |
| 输入非法     | 文件格式不支持         | 拦截上传           | "不支持该文件格式，支持格式：PDF/Word/Excel/PPT/TXT/图片" |
| 对象不存在   | 项目知识空间不存在     | 拦截上传           | "项目不存在"                                              |
| 状态不合法   | 项目知识空间已停用     | 拦截上传           | "项目已停用，无法上传"                                    |
| 权限不足     | 企业客户无项目访问权限 | 拦截上传           | "您无该项目访问权限"                                      |
| 重复操作     | 同一文件快速重复上传   | 允许，创建新记录   | "上传成功"                                                |
| 并发冲突     | 多人同时上传           | 分别处理，独立记录 | "上传成功"                                                |
| 引用关系冲突 | 项目被删除后上传       | 拦截上传           | "项目已不存在"                                            |

### 10.1 特殊边界补充

- **大文件上传**：超过一定大小的文件支持分片上传、断点续传
- **批量上传**：支持一次选择多个文件批量上传，每个文件独立处理
- **网络中断**：上传过程中网络中断，支持重新上传或续传

## 12. 非功能要求

| 类别     | 要求                                                   |
| -------- | ------------------------------------------------------ |
| 一致性   | 上传状态在列表页、详情页应保持一致                     |
| 可用性   | 上传操作应具备明确的成功/失败反馈                      |
