## 🎯 设计原则

### 核心价值观
1. **清晰优先** - 信息层级分明，重要内容突出
2. **简洁高效** - 去除多余装饰，聚焦功能本身
3. **一致性** - 统一的视觉语言和交互模式
4. **易用性** - 降低认知负担，提升操作效率

### 视觉特征
- ✅ 大量留白，视觉呼吸感强
- ✅ 扁平化设计，无多余装饰
- ✅ 使用细线分隔，轻盈感
- ✅ 悬浮卡片效果，轻微圆角
- ❌ 避免渐变、阴影过度使用
- ❌ 避免过多颜色混搭

## 📝 字体规范

### 字体家族
- **中文**：系统默认字体（优先级：PingFang SC, Microsoft YaHei, sans-serif）
- **英文/数字**：系统默认字体（优先级：-apple-system, BlinkMacSystemFont, Segoe UI, sans-serif）
- **代码**：Consolas, Monaco, monospace

### 字号系统（单位：px）

| 用途 | 字号 | 行高 | 字重 | 使用场景 |
|------|------|------|------|----------|
| 大标题 | 24px | 32px | 600 | 页面主标题 |
| 标题 | 20px | 28px | 600 | 模块标题 |
| 副标题 | 16px | 24px | 600 | 卡片标题、顶栏标题 |
| 正文 | 14px | 22px | 400 | 表格内容、表单标签 |
| 辅助文字 | 13px | 20px | 400 | 菜单项、按钮文字 |
| 小字 | 12px | 18px | 400 | 说明文字、表头 |
| 超小字 | 11px | 16px | 400 | 次要说明 |

### 字重（Font Weight）
- **Regular (400)**：正文、描述文字
- **Medium (500)**：一级菜单项
- **SemiBold (600)**：标题、强调文字
- **Bold (700)**：数据展示、特殊强调

### 字体颜色使用规则
1. **标题**：使用 `#111827`（标题文字）
2. **正文**：使用 `#374151`（正文文字）
3. **次要信息**：使用 `#6b7280`（次要文字）
4. **禁用状态**：使用 `#94a3b8`（禁用文字）
5. **链接/强调**：使用 `#3b82f6`（主色）

## 📏 间距系统

### 基础间距单位
采用 8px 栅格系统，所有间距都是 8 的倍数

| 名称 | 值 | 使用场景 |
|------|-----|----------|
| xs | 4px | 图标与文字间距 |
| sm | 8px | 按钮内边距、小组件间距 |
| md | 12px | 表单字段间距 |
| base | 16px | 卡片内边距、标准间距 |
| lg | 24px | 页面内边距、模块间距 |
| xl | 32px | 大模块间距 |
| 2xl | 48px | 页面级大间距 |

### 具体应用

#### 页面布局间距
- 页面外边距：`24px`（lg）
- 卡片之间间距：`16px`（base）
- 卡片内边距：`16px`（base）

#### 表单间距
- 表单字段间距：`12px`（md）
- 标签与输入框间距：`4px`（xs）
- 表单按钮组间距：`8px`（sm）

#### 表格间距
- 单元格内边距：`12px`（md）
- 表格外边距：`16px`（base）

#### 按钮间距
- 按钮内边距：`8px 16px`（sm base）
- 按钮之间间距：`8px`（sm）

#### 导航间距
- 菜单项内边距：`8px 12px`（sm md）
- 菜单项之间间距：`4px`（xs）
- 侧边栏内边距：`16px`（base）

## 🖱️ 交互规范

### 悬停效果（Hover）

#### 按钮
- 主按钮：背景色加深（#2563eb）
- 次要按钮：背景色变浅（#f9fafb）
- 文字按钮：添加背景色（#f1f5f9）
- 过渡时间：`150ms ease`

#### 表格行
- 背景色：#fafafa
- 过渡时间：`150ms ease`

#### 菜单项
- 背景色：#f1f5f9
- 过渡时间：`150ms ease`

#### 卡片
- 阴影增强：`0 4px 6px rgba(0,0,0,0.1)`
- 过渡时间：`200ms ease`

### 点击效果（Active）
- 轻微缩放：`scale(0.98)`
- 过渡时间：`100ms ease`

### 聚焦效果（Focus）
- 输入框：边框加粗为 2px，颜色 #3b82f6
- 按钮：添加外轮廓 `outline: 2px solid #3b82f6`，`outline-offset: 2px`
- 过渡时间：`150ms ease`

### 禁用效果（Disabled）
- 透明度：`opacity: 0.5`
- 鼠标样式：`cursor: not-allowed`

### 加载状态（Loading）
- 使用圆形旋转图标
- 颜色：#3b82f6
- 大小：16px（按钮内）/ 24px（页面级）
- 动画：持续旋转，`1s linear infinite`

### 动画时长建议
- 微交互：100-150ms（按钮点击、悬停）
- 标准交互：200-300ms（菜单展开、卡片悬停）
- 复杂交互：300-500ms（对话框出现、页面切换）

## 📦 组件导出规范

### 命名规则
```
组件类型/页面名称/组件名称-状态
例如：
- Button/Primary-Default
- Button/Primary-Hover
- Input/Text-Default
- Input/Text-Focus
- Table/Row-Default
- Table/Row-Hover
```

### 导出设置
- **格式**：推荐 SVG（图标）/ PNG（截图）
- **倍率**：1x（Web）/ 2x（高清屏）
- **颜色空间**：sRGB
- **单位**：px

### 图标规范
- **尺寸**：16px / 18px / 20px / 24px（图标尺寸统一）
- **线宽**：1.5px - 2px
- **风格**：线性图标（Outline）
- **颜色**：单色，建议使用 #64748b 作为默认色
- **边距**：图标四周至少留 2px 间距

## 🎓 使用建议

### Figma 设计流程

#### 1. 创建颜色样式（Color Styles）
在 Figma 中创建以下颜色样式：
- Primary/Main (#3b82f6)
- Primary/Light (#eff6ff)
- Primary/Dark (#2563eb)
- Neutral/900 (#111827)
- Neutral/700 (#374151)
- Neutral/500 (#6b7280)
- Neutral/400 (#94a3b8)
- Background/Page (#fafafa)
- Background/Card (#ffffff)
- Border/Main (#e5e7eb)
- ... (其他颜色同理)

#### 2. 创建文本样式（Text Styles）
- Heading/Large (24px/600/#111827)
- Heading/Medium (20px/600/#111827)
- Heading/Small (16px/600/#111827)
- Body/Default (14px/400/#374151)
- Body/Small (13px/400/#64748b)
- Caption (12px/400/#6b7280)

#### 3. 创建组件库（Components）
- 按钮组件（包含各种状态）
- 输入框组件（包含各种状态）
- 表格组件
- 卡片组件
- 标签组件
- 菜单项组件

#### 4. 使用 Auto Layout
- 利用 Figma 的 Auto Layout 设置间距
- 确保间距使用 8px 栅格
- 设置合理的 padding 和 gap

#### 5. 组件变体（Variants）
将同一组件的不同状态设置为变体：
- Button: type (primary/secondary/text) × state (default/hover/disabled)
- Input: state (default/focus/error/disabled)
- Menu Item: state (default/hover/selected)

### 设计交付

#### 交付给开发的内容
1. **设计稿**：完整的页面设计图
2. **切图资源**：图标、图片等资源
3. **标注说明**：特殊交互、动画效果说明
4. **设计规范文档**：本文档

#### 开发对接要点
- 颜色值直接使用 HEX 格式
- 间距使用 px 单位
- 圆角、边框宽度使用 px 单位
- 字号使用 px 单位
- 阴影参数：X偏移 Y偏移 模糊 扩展 颜色
